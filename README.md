## How to follow along

- **Minimum**: any AI assistant in the browser (Claude, ChatGPT, Gemini). Upload the files when the prompts in the slides mention them.
- **Better**: the [Claude](https://claude.com/download) desktop app (with Claude Code) or the [ChatGPT](https://chatgpt.com/download) desktop app (with Codex), or [VS Code](https://code.visualstudio.com) with their extensions; and [Miniconda](https://www.anaconda.com/download/success?reg=skipped-miniconda) for Python. Download this repository (Code → Download ZIP), unzip it and open the whole folder; the prompts in the slides refer to files inside `coop-project/`.
